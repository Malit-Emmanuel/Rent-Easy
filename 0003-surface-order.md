# ADR-0003 Web dashboard first, mobile second

Status: Accepted | Date: 2026-09-30

## Decision
The professional web dashboard is built first (onboarding properties, units, verification, payment status, exceptions). The Expo app follows and targets field workflows: verification, inspections, photos/GPS, operational updates.

## Consequences / open items
Tenant mobile-web experience must still meet low-bandwidth budgets because tenants will use phones before any native app exists. Reorders build phases B2-B8; see updated build plan.
