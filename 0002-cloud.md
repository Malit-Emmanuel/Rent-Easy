# ADR-0002 Cloud and region

Status: Hosting superseded by ADR-0010; data-residency items remain open | Date: 2026-09-30

## Decision
AWS, primary region af-south-1 (Cape Town), managed services where practical.

## Consequences / open items
OPEN: (1) confirm every planned AWS service is available in af-south-1; (2) hosting Kenyan personal data in South Africa is a cross-border transfer, so counsel must confirm Kenya data-protection requirements before ID data is stored there; (3) confirm ID-image storage policy. Until confirmed, store no real ID images.
